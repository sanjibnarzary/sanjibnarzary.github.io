**TrueSeal** is an enterprise-grade, self-custodial cryptographic digital signature and verification platform built with modern Android, Jetpack Compose, Room, and Firebase. It empowers individuals, developers, legal professionals, and organizations to cryptographically seal and verify documents, PDFs, images, archives, and arbitrary data with mathematically provable authenticity and non-repudiation.

---

## 🔒 Core Cryptographic Architecture

- **Asymmetric Signature Scheme**: NIST P-256 (secp256r1) Elliptic Curve Digital Signature Algorithm (`SHA256withECDSA`).
- **Universal DSC & eSign Verifier**: Automated verification of standard PDF Digital Signature Certificates (DSC) including **Aadhaar eSign**, **e-PAN Digital Signatures**, **Income Tax Return (ITR-V)** DSCs, **Govt / CCA Certified DSCs**, and standard PKCS#7 / PAdES signatures.
- **Cryptographic Hashing**: FIPS 180-4 Secure Hash Standard (SHA-256) digest computed stream-by-stream.
- **Hardware-Backed Self-Custody**: Private keys are generated and held exclusively inside device-local secure hardware; private keys **never** transit network sockets or third-party servers.
- **Passphrase Encryption (BIP-39 Style)**: Private key vault encrypted using **AES-256-GCM** with keys derived via **PBKDF2WithHmacSHA256** (12,000 iterations and cryptographic salt).
- **12-Word Mnemonic Recovery**: Deterministic mnemonic phrase backup with a mandatory pre-activation verification challenge.
- **Tamper Detection & Verification**: Instant cross-user signature verification with a prominent **Big Green Verified Badge** on authenticity and an alert **Red Cross Warning** on any file alteration (even 1-bit drift).
- **Configurable Watermark Overlay**: Customizable in Settings as **Multi-line** (default) or **Single-line** (clean, non-wrapping) across **6 positions** (Bottom Right [default], Bottom Center, Bottom Left, Top Right, Top Center, Top Left).

## 🚀 System File Intent Integration ("Open With")

TrueSeal integrates natively into Android's system file manager and share sheets:
- **Open with TrueSeal Verify**: Directly open any PDF, signed copy, or certificate from the Android system files to inspect signature validity, certificate hierarchy, and byte-range integrity.
- **TrueSeal Sign Document**: Directly select any document, image, or file from system files to sign and stamp it with TrueSeal's local cryptographic keys.

---

## 📁 Separate File Managers & Verification Audit

TrueSeal includes two dedicated file managers:
1. **Exported Files (File Manager)**:
   - Dedicated screen showing all exported signed files, embedded copies, and standalone `.trueseal` certificates.
   - Filter by format (PDFs, Images, Certificates).
   - Quick actions to open in external viewer, share, re-verify integrity, or delete.
2. **Verified Documents History**:
   - Comprehensive audit trail of all verified documents and DSCs.
   - Filter by status (Valid, Tampered/Invalid) and category (Aadhaar/Govt DSC, TrueSeal).
   - Detailed certificate audit inspection (Common Name, Organization, Issuer CA, Signing Timestamp, Serial Number, Byte-Range coverage).
   - Shareable verification proof reports.
