# About Narzary PDF Studio Pro

Narzary PDF Studio Pro is an offline Android workspace for common PDF tasks. It provides dedicated tools to merge and split files, organize pages, annotate documents, extract text, convert formats, add signatures, and manage a local document library.

## Document tools

The submitted product information describes on-device OCR and document intelligence, scanning to PDF, office and image conversion, compression, password protection, and permanent redaction. PDF operations are designed to work locally on the device.
