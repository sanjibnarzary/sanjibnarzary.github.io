## Read across file types

Uniview brings together readers for Word documents (`.docx`, `.doc`, `.rtf`), spreadsheets (`.xlsx`, `.xls`, `.csv`, `.tsv`), presentations (`.pptx`, `.ppt`, `.odp`), PDFs, images, Markdown, and programming code. Open files from the in-app document manager or through Android's “Open with” flow.

## Navigate and work with files

Read documents page by page, move through spreadsheet rows and columns, and view presentations as slides. Inspect source code with syntax highlighting and line numbers, or use the described editing tools for documents, spreadsheets, and images.
