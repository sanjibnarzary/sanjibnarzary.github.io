# About Uniview

Uniview brings common document, spreadsheet, presentation, PDF, image, Markdown, and source-code readers together in one Android app. Files can be opened from the in-app manager or through Android's “Open with” flow.

## One place for many file types

The product information describes page-based document reading, spreadsheet navigation and editing, slide viewing, image editing, and syntax-highlighted code viewing.
