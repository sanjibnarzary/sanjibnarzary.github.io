# Narzary PDF Studio Pro - All-in-One Offline PDF Powerhouse

**Narzary PDF Studio Pro** is a comprehensive, privacy-first, 100% offline Android PDF application engineered for mobile phones and tablets. Every single PDF tool operates in its own **dedicated, full-page screen** with rich interactive controls, live up-and-down scrollable page previews, device storage / external drive pickers, Room Database integration, and standardized timestamped file saving.

---

## 🛠️ Dedicated Tool Screens & Capabilities

### 1. Merge PDF Screen
- **Storage & External Drive Picker:** Select multiple PDF documents directly from device internal storage, SD cards, USB drives, or the built-in Room database.
- **Visual Order Arrangement:** Reorder documents up and down, inspect page counts and file sizes, or remove items.
- **Timestamped Output:** Combines all documents and automatically saves to local storage with the structured filename: `narzary_pdf_studio_YYYY-MM-DD_HH-mm-ss_merged.pdf`.

### 2. Split PDF Screen
- **Storage Picker:** Select PDF from device storage or Room library.
- **Scrollable Up-and-Down Page Preview:** Scroll through high-resolution rendered pages with dynamic badges (`Page X of Y`) to visually inspect pages before splitting.
- **Page Range Specification:** Input custom page ranges (e.g. `1-3, 5`) or select quick chips (e.g. `First Page`, `All Pages`).
- **File Storage Persistence:** Extracted documents are saved directly into device storage with universal naming.

### 3. Organize PDF Screen
- **Visual Grid Management:** Interactive thumbnail grid of every page in the document.
- **Rearrange Pages:** Move any page earlier or later in sequence with directional controls.
- **Delete Specific Pages:** Mark unwanted pages for deletion with instant feedback.
- **Rotate Pages:** Rotate individual pages (90°, 180°, 270°) or all pages at once.
- **Save to Storage:** Compiles the rearranged, rotated, and filtered document with universal naming.

### 4. Compress PDF Screen
- **Three Quality Tiers:**
  - **Low Compression:** Preserves maximum visual sharpness and high-fidelity rendering.
  - **Medium Compression (Balanced):** Optimal reduction with clear text and graphics.
  - **High Compression (Smallest Size):** Aggressive file size reduction ideal for email attachments and messaging apps.
- **Live Estimation:** Compares original KB vs. estimated compressed KB with percentage savings.

### 5. Edit & Annotate PDF Screen
- **Interactive Annotation Canvas:** Direct gesture-based drawing over rendered PDF pages.
- **Freehand Pen Tool:** Smooth multi-color ink annotation with adjustable stroke thickness.
- **Highlighter Tool:** Semi-transparent highlighting for text and paragraphs.
- **Vector Text Insertion:** Add typed text labels, verification stamps, and notes directly onto any page.

### 6. OCR Text Extraction Screen (ML Kit Integration)
- **On-Device Machine Learning:** Powered by Google ML Kit Text Recognition with zero cloud dependency.
- **Multilingual Recognition:** Detects and extracts text from scanned or non-selectable PDF pages.
- **Actions:** One-tap clipboard copy, live text editing, and text export.

### 7. Insert Page Numbers Screen
- **Live Scrollable Preview:** Visual preview before inserting headers or footers.
- **Placement Options:** Bottom Center, Bottom Right, Bottom Left, Top Center, Top Right, Top Left.
- **Format Options:** `Page X of Y`, `X / Y`, `- X -`.

### 8. Custom Watermark Screen
- **Live Preview:** Scroll through pages to inspect watermark overlay in real time.
- **Customizable Controls:** Custom text string, opacity slider (10% to 90%), rotation angle (-90° to +90°), and color palette.

### 9. Digital Signature & Security Screen
- **Touch / Stylus Signature Pad:** Draw biometric signatures directly on device with stroke smoothing.
- **Permanent Redaction:** Destructive, irreversible blackouts over sensitive data with zero data recovery.
- **Password Protection & Unlock:** Secure PDF files with AES encryption.

### 10. Office & Image Converters
- **Word to PDF / Excel to PDF / PowerPoint to PDF / HTML to PDF:** Convert formatted text, structured tables, and web content into PDF documents.
- **Scan to PDF:** High-contrast camera scanner with B&W, Grayscale, and Color document filters.
- **PDF to Image & Text Export:** Convert PDF pages into JPG images or plain text files.

### 11. AI & PDF Intelligence (100% Offline)
- **Document Summarizer:** Extracts key highlights, executive summaries, and action items without internet.
- **Multilingual Translator:** Supports **all 22+ official Indian languages** (Hindi, Bengali, Telugu, Marathi, Tamil, Urdu, Gujarati, Kannada, Malayalam, Odia, Punjabi, Assamese, Maithili, Santali, Kashmiri, Nepali, Konkani, Sindhi, Dogri, Manipuri, Bodo, Sanskrit) plus major global languages.
- **Smart Categorizer:** Categorizes documents into Invoices, Legal Contracts, Medical Records, Receipts, and Reports.

### 12. Local File Explorer (Room Database)
- **SQLite / Room DB:** Fast, searchable metadata catalog of all local PDF files.
- **File Management:** Search by title, filter by category, favorite/star documents, rename, delete, inspect details, and open in any tool.

## 🔒 Watermark Policy & Universal Naming

1. **Free Edition Watermark:** Every document saved under the Free edition includes the fixed stamp **"Narzary PDF Studio"** permanently affixed to the bottom right of every page.
2. **Pro Edition:** Upgraded users enjoy completely watermark-free exports.
3. **Universal Naming Convention:** All processed documents are automatically saved as `narzary_pdf_studio_YYYY-MM-DD_HH-mm-ss.pdf` (or `narzary_pdf_studio_YYYY-MM-DD_HH-mm-ss_merged.pdf` for merged documents).
